Export from your phone app, then upload the file here. Parsed entirely in your browser — nothing is uploaded anywhere.

WeChat Pay — mainland RMB wallet

  1. WeChat → 我 (Me) → 服务 (Services) → 钱包 (Wallet)
  2. Tap 账单 (Bill) top-right
  3. Tap ··· top-right → 下载账单 (Download Bill)
  4. Choose 用于个人对账 (For Personal Reconciliation) — not 用作证明材料, pick dates
  5. Face-verify → the bill arrives in the 微信支付 chat → tap 查看详情 → download
  6. If it's a zip, unzip it → upload the .csv / .xlsx below

On WeChat Pay HK, if you don't see 下载账单, file export isn't offered on your wallet — log those transactions with the + button instead.

Alipay — mainland

  1. Alipay → 我的 (Me) → 账单 (Bill)
  2. Tap ··· top-right → 开具交易流水证明
  3. Choose 用于个人对账 (For Personal Reconciliation), pick dates
  4. Wait for the message → download the file
  5. Upload the .csv / .xlsx below
